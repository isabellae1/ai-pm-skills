# AI PRD 自查清单

在 SKILL.md 第 8 步自查时使用；评审他人的 PRD 时，按此清单逐项检查，输出"缺失项 / 需修改项 / 建议"。

## 必备项（缺一项即不完整）

- [ ] 写明了**为什么要用 AI**，并考虑过非 AI 方案
- [ ] AI 的**输入、输出和使用者**定义清楚
- [ ] 有**离线评测集**的构建计划，且包含难例和应拒答的问题
- [ ] 每个关键指标都有**具体的上线门槛**，至少有一条一票否决项
- [ ] 列出了**失败模式**，致命级失败都有兜底方案
- [ ] 标明了每类动作的**人工介入级别**
- [ ] 完成了**数据与合规**检查，并标注需法务确认的事项

## 需求质量

- [ ] 问题陈述基于证据（用户研究、数据、反馈），而不是假设
- [ ] 成功指标同时包含**业务指标**和**AI 质量指标**
- [ ] 写明了**不做什么**（范围外）
- [ ] 用户故事的验收标准可测试
- [ ] AI 不可用时有**降级方案**

## 常见问题

| 问题 | 表现 | 修改方向 |
|---|---|---|
| 为了 AI 而 AI | 找不到 AI 比规则更好的理由 | 回到第 2 步，或缩小 AI 的使用范围 |
| 指标空泛 | "回答要准确""体验要好" | 改成可测量的指标和阈值 |
| 只有正常路径 | 没写 AI 答错、超时、拒答时界面怎么显示 | 补充异常状态的交互和文案 |
| 评测集太"干净" | 只有规整的标准问题 | 补充口语化、错别字、超范围的问题 |
| 忽略成本 | 没有调用量和成本估算 | 补充成本预算 |
| 合规留白 | 涉及个人数据但没有数据部分 | 补充数据流向和授权说明 |
| 一步到位 | 直接全量上线 | 改为分阶段上线，写明每阶段的进入条件 |
